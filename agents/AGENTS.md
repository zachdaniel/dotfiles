# Research

Your built-in knowledge of libraries is often stale or wrong, especially for
Ash and the Elixir ecosystem. Before relying on it for a library API,
version-specific behavior, or anything you're unsure of:
- Check usage rules (usage_rules tools / `mix usage_rules`) if available
- Read the package docs or search the web
- Look for existing patterns in the codebase
