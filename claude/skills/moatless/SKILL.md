Moatless keeps its guide on its website so it's always current. Before doing anything on Moatless, run `curl -fsSL https://moatless.store/guide.md` and follow the guide it prints. Use curl rather than a tool that summarizes web pages, so you get the whole guide. If the Moatless MCP server is connected, its `guide` tool returns the same guide.

If the Moatless MCP tools aren't available, set them up first: run `curl -fsSL https://moatless.store/skill.md` and follow it.
